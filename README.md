# LLM辅助隐函数梯度多孔结构在线发泡打印鞋底研制
本项目旨在开发一套从自然语言需求到实物鞋底的快速开发链路：以力-位移加载/卸载曲线为统一性能评价依据，利用大语言模型（LLM）辅助生成隐函数多孔结构方案，通过在线发泡3D打印工艺一体成型梯度多孔鞋底样件，并通过高通量力学测试台架完成性能验证与结构设计的迭代优化。

## 数据源与验证状态

- **知识库唯一真源**：`database` 分支的 `database/4_structure_master/`。`data/Structure_Master_V1.0.xlsx` 是优化器为可复现保留的只读副本，请勿在两处分别修改，以免静默漂移。
- **真实 LLM 调用路径已实现、尚未实测**：演示或答辩时不要表述为“已验证可用”。验收标准是 `run_log.json` 中出现 `usage_source: "reported"`。
- 离线复现请显式使用 `--llm-backend mock`；默认配置为 `siliconflow`，运行时会弹窗要求输入密钥。
