# 高支撑 + 高弹性 TPMS 隐函数组合方案

> 目标：在单胞 `[0, 2π)^3` 内搜索由三角基函数线性组合构成的隐式曲面  
> `F(x,y,z) = Σ c_i · token_i(x,y,z) = 0`，同时兼顾 **高支撑（高刚度/高承载）** 与 **高弹性（高可恢复变形/高回弹）**。
>
> **重要声明：本文所有 score 都是几何代理指标，不是 FEA 结果。**  
> 评价器只计算相对密度、周期性连通性、曲率、法向各向同性、比表面积等几何量；没有应力、应变、屈曲、屈服、疲劳或制造约束。代理分只能用于排序与搜索，不能当作真实刚度/强度/回弹模量的预测值。

---

## 0. 结论先行

1. 在本次实际运行的 50 轮 LLM(模拟) + 50 轮随机基线中，**得分最高的组合是 Gyroid 型三周期极小曲面及其近等价变体**（0.9449~0.9511）。  
   种子 S001 Gyroid 本身已经达到 0.9511，搜索没有找到严格更高的新结构；生成候选在 0.9449、0.9338、0.9194 附近形成了三个高质量替代方案。
2. **LLM(模拟) 明显优于随机基线（均值/中位数/入池率），但两者都没有超过种子 Gyroid。**  
   - LLM(模拟)：候选均分 0.8456，中位数 0.9038，入池率 38%（19/50），最高 0.9511；  
   - 随机基线：候选均分 0.5533，中位数 0.5742，入池率 20%（10/50），最高 0.7742；  
   - 均值差 +0.2923，Mann–Whitney U=2408，p≈7.3×10⁻¹⁶，rank-biserial=0.926。  
   - **最高分是平局（都等于种子 0.9511），但随机基线从未达到种子水平。**
3. 该结论是一个有价值的“负结果”：在当前几何代理下，**Gyroid 已接近高支撑+高弹性的代理最优**；Diamond 与 Primitive 是不同力学侧重的替代方案，而不是全面超越 Gyroid 的方案。  
   真实力学中 P 面通常更偏拉伸主导、D 面更偏弯曲主导，代理分无法完全区分这种拓扑差异，必须用 FEA/实验进一步标定。

## 3. 逐条组合理由与力学/几何解释

### 3.1 G-变体（Gyroid 手性变体）—— 综合最优

**隐式方程：**

```text
F(x,y,z) = -0.9446·sin(x)cos(y) + 0.9723·sin(y)cos(z) + 0.9816·sin(z)cos(x) = 0
```

**每个基函数的作用：**

- `sin_x_cos_y`：把 x 向正弦与 y 向余弦耦合，形成沿 x-y 对角方向的螺旋通道；在 G 面中负责一条手性骨架。
- `sin_y_cos_z`：同理形成 y-z 螺旋通道；与第一项错开 90°，避免三条通道在同一平面相交。
- `sin_z_cos_x`：闭合第三组 z-x 手性通道，使三组通道在三维空间中循环连通。

这三项是 Gyroid 的标准三项式。三个轴向的循环耦合带来**三维各向同性**（本候选 isotropy=0.972；种子 S001 为 1.000），不会像单轴余弦那样退化成层状结构。G 面是极小曲面，平均曲率接近零（H_mean=0.033），因此：

- **支撑侧**：曲面光滑、无尖角，载荷沿连续曲面传递，弯曲应力集中小；相对密度 0.500 提供足够的承载体积，support 代理 0.9747。
- **弹性侧**：低曲率、双连续、曲率分布均匀（uniformity=0.958），变形时不容易在局部节点产生屈服/屈曲，可恢复变形能力好；elastic 代理 0.9085。

**系数与符号：**

- 三个系数幅值 0.9446 / 0.9723 / 0.9816 非常接近，保持了近似三重对称；没有明显偏向某一轴，所以各向同性保持得很好。
- 第一项取负号（`-0.9446`）等价于改变该手性项的相位/手性方向，得到 Gyroid 的镜像/互补变体；`F=0` 曲面本身仍是 Gyroid 型，但实体相 `F<=0` 的选择会翻转，是本次搜索找到的“近种子但非完全重复”的变体。
- 由于 `F=0` 对整体正比例缩放不变，系数整体乘任意正数不改变曲面；真正有意义的是**比值**。本组比值约为 `-0.96 : 0.99 : 1.00`，接近 1:1:1。

**继承/变异关系：** 继承 S001 Gyroid 的三项手性模板；变异为第一项符号翻转 + 三个系数独立小幅扰动（模板 `Gyroid+flip[0]`），属于同一拓扑家族内的手性/相位变体。

**适用场景：** 多轴载荷、需要各向同性刚度的承载结构；换热器/生物支架/吸能结构；希望同时获得较高刚度与较好回弹的场合。**这是本次搜索推荐的首选。**

---

### 3.2 D-变体（Diamond 近等价）—— 弯曲主导、变形稳定

**隐式方程：**

```text
F(x,y,z) = 0.9235·cos(x)cos(y)cos(z) - 0.9301·sin(x)sin(y)sin(z) = 0
```

**每个基函数的作用：**

- `cos_x_cos_y_cos_z`：三轴余弦乘积，形成三维棋盘式的“正相”网络；它是 D 面的主项，负责节点与对角韧带的空间分布。
- `sin_x_sin_y_sin_z`：三轴正弦乘积，形成“反相”网络；与第一项相减后，两个网络互相穿插，得到 D 面的双连续两相结构。

D 面同样是极小曲面（H_mean=0.054），但它的拓扑更接近**弯曲主导**：节点处曲率更集中、比表面积更大（0.567 vs Gyroid 0.473）。因此：

- **支撑侧**：连续双网络 + 相对密度 0.500，support 代理 0.9664；略低于 Gyroid，原因是曲率/比表面积稍高。
- **弹性侧**：弯曲主导的节点允许更大的可恢复弯曲变形，适合吸能与稳定变形；elastic 代理 0.8940。曲率虽比 G 高，但仍属于光滑极小曲面，没有尖角。

**系数与符号：**

- 两项幅值 0.9235 / 0.9301，比值约 `-1 : 1.007`，非常接近标准 D 面 `coscoscos - sinsinsin`。
- 负号使第二项反相，形成双连续两相；若改成同号，拓扑会显著变化。
- 系数整体缩放不改变 `F=0`；本候选相对种子 S003 只是轻微改变了幅值比，因此是 D 面的近等价变体。

**继承/变异关系：** 直接继承 S003 Schwarz Diamond 的两项模板；变异为两项系数独立扰动（模板 `Diamond`），保留 D 面拓扑与双连续性。

**适用场景：** 需要**稳定变形、吸能、可恢复弯曲**的场合，例如缓冲/吸能芯、柔性生物植入体、需要较大可恢复挠度的承载结构。若主要目标是最高刚度，Gyroid/P 面更合适；若目标是吸能与变形稳定，D 面更有优势。

### 3.3 D+x（Diamond + 轴向余弦）—— 单轴增强的各向异性方案

**隐式方程：**

```text
F(x,y,z) = 1.0472·cos(x)cos(y)cos(z) - 1.0811·sin(x)sin(y)sin(z) + 0.1942·cos(x) = 0
```

**每个基函数的作用：**

- 前两项：D 面双网络（同 3.2），提供双连续、弯曲主导的基体。
- `cos_x`：在 D 面上叠加一个沿 x 方向的余弦调制，相当于在 x 方向增加一条“直通道/轴向承载路径”；它把原本三重对称的 D 面轻微拉向 x 轴。

**支撑/弹性权衡：**

- 小幅 `cos_x`（0.1942）使 isotropy 从 1.000 降到 0.975，曲率从 0.054 升到 0.067；support 代理从 0.9664 降到 0.9533，elastic 从 0.8940 降到 0.8779。
- 从代理指标看，它是**用少量各向同性和平滑性换取 x 向载荷路径**的方案：如果实际工况是单轴压缩/拉伸，x 向附加通道可能提高该方向刚度；但多轴载荷下不如纯 D/G。
- 真实力学中，`cos_x` 的 P 面分量是拉伸主导的，理论上有利于轴向刚度；但几何代理无法计算方向刚度张量，因此这里只能给出“方向性设计”的定性判断，不能声称它一定提高 x 向模量。

**继承/变异关系：** 继承 S003 D 面两项，并引入 S002 P 面的 `cos_x` 单项，属于 D→P 的轴向杂交（模板 `Diamond_plus_x`）。与种子 S005 Neovius（3cosx+3cosy+3cosz+4coscoscos）相比，本方案只保留一个轴向余弦，更轻量、更各向同性。

**适用场景：** 已知主载荷方向为 x 轴、需要定向刚度增强的场合；不建议用于多轴复杂载荷。

### 3.4 D+y（Diamond + y 向余弦）—— 更强的单向偏置

**隐式方程：**

```text
F(x,y,z) = 1.0953·cos(x)cos(y)cos(z) - 0.9327·sin(x)sin(y)sin(z) + 0.3112·cos(y) = 0
```

**每个基函数的作用：**

- 前两项仍是 D 面双网络。
- `cos_y` 系数更大（0.3112），对 y 向的偏置更强，因此各向同性更低（isotropy=0.945）、曲率更高（H_mean=0.089）。

**支撑/弹性权衡：**

- support 0.9346、elastic 0.8545，均低于 D+x，说明“轴向余弦系数越大，代理分越低”：过强的单轴调制会破坏双连续对称性、增加曲率集中，从而损害弹性。
- 该候选在 r46 未入池（当时池内最差 0.9339），但作为“参数扫描点”保留了数据，说明**轴向增强存在最优上限**：小系数可做定向设计，大系数会显著降低综合性能。

**继承/变异关系：** 与 D+x 同源（D 面 + 单轴余弦），只是轴向改为 y、系数更大；可与 D+x 组成“x/y 定向增强”的参数对照。

**适用场景：** y 向主载荷的定向设计；或作为研究“轴向偏置强度—各向同性—弹性” trade-off 的参数样本。

### 3.5 G-D 混合（交叉变异）—— 对称性破坏的代价

**隐式方程：**

```text
F(x,y,z) = 1.0295·cos(x)cos(y)cos(z) - 0.8589·sin(x)sin(y)sin(z) + 0.8835·sin(x)cos(y) = 0
```

**每个基函数的作用：**

- 前两项：D 面双网络。
- `sin_x_cos_y`：从 Gyroid 借来的一条手性项，系数高达 0.8835；它在 D 面中引入 x-y 螺旋/剪切耦合，使结构同时具有 D 的弯曲节点和 G 的手性通道。

**为什么分数明显下降：**

- isotropy 从 1.000 降到 0.601；H_mean 从 0.054 升到 0.147；support/elastic 分别降到 0.8350 / 0.7533。
- 三项来自不同对称群（D 的三轴奇偶性与 G 的 x-y 手性），叠加后破坏了三重对称，产生曲率集中和方向偏置。几何代理因此给出明显更低的分数。
- 这不是“组合越多越好”的反例：**在没有对称性约束时，增加一项会破坏极小曲面的低曲率优势**。如果目标是扭转/剪切耦合，这种混合可能有意义；如果目标是高支撑+高弹性，纯 G 或纯 D 更好。

**继承/变异关系：** r17 由 S003（D）与 S001（G）交叉得到，保留 D 的两项，再加入 G 的 `sin_x_cos_y` 一项；是“D 基体 + G 手性单侧”的杂交。

**适用场景：** 扭转/剪切主导的变形模式、需要手性-弯曲耦合的 metamaterial；不建议作为高支撑+高弹性的平衡方案。

| `high_support_high_elasticity` | Gyroid 变体 | `[-0.9446, 0.9723, 0.9816]` | 0.9449 | **0.9449** |

同一个三项 Gyroid 模板，通过改变系数符号/幅值，可以在“支撑优先”和“弹性优先”之间移动分数；这说明优化器支持不同的目标输入，但也说明在当前代理下 **Gyroid 家族是三个 profile 的共同最优家族**。真实力学中，P 面（拉伸主导）很可能在高支撑目标下超过 Gyroid，D 面在吸能/大变形目标下更有优势；这需要 FEA 才能分辨。

## 5. 代理指标与真实力学之间的关系（必须明确的局限）

### 5.1 当前评价器算的是什么

- `ρ*`：实体相 `F<=0` 的体素占比；
- `connectivity`：实体相与空相在周期边界下的最大连通分量比例；
- `H_mean / H_p95`：由 `n=∇F/|∇F|`、`H=0.5·div(n)` 得到的等值面平均曲率；
- `isotropy`：等值面法向协方差特征值的最小/最大比，用来排除 1D 层状/2D 柱状退化结构；
- `area/V`：marching cubes 三角面片面积 / 单胞体积；
- `support = 0.32·密度 + 0.18·连通 + 0.20·平滑 + 0.22·各向同性 + 0.08·比表面积窗口`；
- `elastic = 0.25·连通 + 0.25·平滑 + 0.15·密度窗口 + 0.08·均匀性 + 0.19·各向同性 + 0.08·比表面积窗口`；
- `score = 0.55·support + 0.45·elastic`。

这些量**没有一个来自 FEA**。它们只能说明“几何上是否连续、光滑、各向同性、密度适中”，不能说明“刚度是多少、屈服/屈曲何时发生、回弹率是多少”。

### 5.2 从几何代理到真实力学，需要补哪些验证

1. **FEA（周期性单胞，线性弹性）**：施加 x/y/z 单轴、剪切、双轴载荷，计算有效刚度张量 `C_ijkl`、各向异性比、Gibson–Ashby 标度 `E*/Es ~ ρ*^n`，标定 stretching-dominated（n≈1）与 bending-dominated（n≈2）的差异。
2. **非线性 FEA**：大变形、几何非线性屈曲、弹塑性屈服、节点应力集中、可恢复应变与能量吸收（滞回环）。
3. **薄壁/实体化**：当前是 skeletal `F<=0`；真实 TPMS 常用 sheet 型实体 `|F| <= t·|∇F|`。需要做厚度 `t` 与相对密度扫描（如 ρ*=0.15/0.25/0.35），重新评价支撑与弹性。
4. **制造约束**：SLM/SLA 最小特征尺寸、粉末去除、残余应力、表面粗糙度；高比表面积/高曲率结构（如 S009 Double Diamond）制造难度更大。
5. **实验标定**：单胞压缩试验、循环加载、μCT 几何重建；用实测刚度/回弹/吸能校准代理权重。
6. **多物理场**：如果目标是换热/生物支架，还需 permeability、流体压降、细胞黏附/孔径分布；当前评价器不包含这些。

### 5.3 代理指标的已知偏差

- **极小曲面的 H≈0 掩盖了拉伸/弯曲拓扑差异**：P、G、D 都是极小曲面，H_mean 都很低；代理分主要靠比表面积、各向同性和数值平滑度区分，无法判断 P 的拉伸主导与 D 的弯曲主导。真实高支撑可能更偏向 P，真实高吸能/大变形可能更偏向 D。
- **skeletal 约定使 ρ*≈0.5**：本次所有极小曲面候选的 ρ* 都接近 0.500，密度窗口得分固定在 0.607，无法体现“轻量化 20% 密度”的差异。sheet 型实体化后会改变排序。
- **比表面积窗口是启发式**：`area_target=0.50, sigma=0.22` 是为了压制退化层状（area≈0.31）和过高频细碎网络（area≈1.0），不是物理定律。
- **权重是启发式**：`support/elastic` 子权重和 profile 权重由设计者设定；换一组权重，P/D/G 的排名会变化。本文用三组 profile 做了敏感性展示，但没有做完整的权重扫描。
- **64³ 离散化**：marching cubes 与曲率差分对细小特征有平滑/噪声；更高分辨率会改变绝对分数，但相对排序通常稳定。
- **生成上限 3 项**：种子 S004/S005/S006/S008/S009/S010 有 4~8 项，无法被生成候选完整复现；搜索空间比种子库小。
- **LLM 接口状态**：本次没有真实 LLM API 凭证/网络，`proposer_backend=mock` 是本地上下文感知模拟器（读高分样本、模板、系数扰动、交叉），**不是真实大模型**。因此“LLM 优于随机”应理解为“上下文感知模拟器优于随机”，不能外推为某个真实 LLM 的表现。接入真实 API 的代码路径已实现但未实测。

## 7. 最终建议

1. **若现在就要选一个高支撑+高弹性的代理最优方案**：选 **G-变体**（0.9449），它是本次搜索生成候选中最接近 Gyroid 种子（0.9511）且保持三维各向同性的方案；若允许直接用种子，S001 Gyroid（0.9511）仍是首选。
2. **若真实工况更看重吸能/稳定大变形**：选 **D-变体**（0.9338），并在 FEA 中重点验证弯曲节点处的屈服/屈曲与回弹率。
3. **若存在明确的单轴主载荷**：可试 **D+x**（0.9194）；但必须用 FEA 验证 x 向刚度是否真的提升，因为当前代理分反而下降。
4. **不建议把 G-D 混合（0.7983）当作平衡方案**：它破坏了对称性，曲率集中明显；仅适合扭转/剪切耦合等特殊需求。
5. **下一步优先级**：先做 sheet 实体化 + 相对密度扫描（0.15/0.25/0.35），再做线性弹性 FEA（有效刚度张量）与非线性压缩/回弹 FEA；用实测结果重新校准 `support/elastic` 权重，然后再决定 P/G/D 的最终工程选择。
